# ЗАКЛЮЧЕНИЕ

В ходе выполнения практической работы была разработана система классификации продукции на примере ассортимента комплектующих для ПК и серверов, включающая базу данных и серверную часть приложения. Реализованный классификатор позволяет гибко управлять иерархией категорий, конечными комплектующими и их характеристиками без изменения программного кода.

Поставленная цель была достигнута: разработана структура базы данных, реализованы основные операции для работы с категориями, товарами и спецификациями, а также обеспечено взаимодействие с системой через серверную часть. Результаты тестирования показали корректность работы приложения и его соответствие поставленным требованиям.
